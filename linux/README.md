# chikota desktop widget for Linux

This package installs an always-on-top desktop library widget for X11 and Wayland desktops. Browse every bookmark, filter pinned links and collections, add or delete bookmarks, pin and unpin links, and create or remove collections without opening the browser. The last successful response remains available offline.

Resize the widget freely between its compact and expanded limits. Its dimensions and desktop position are restored on the next launch.

## install

1. Ensure Python 3 and Tkinter are installed. Tkinter is commonly packaged as `python3-tk` on Debian/Ubuntu or `python3-tkinter` on Fedora.
2. Extract the download, open a terminal in the extracted folder, and run `./install.sh`.
3. Launch **Chikota Desktop Widget** from the applications menu.
4. Paste your Chikota address and the one-time connection code generated by the web app.

The installer writes only to your user directories under `~/.local` and `~/.config`. It also adds a user autostart entry. The connection code is stored in the desktop Secret Service when `secret-tool` is available; otherwise it is kept in a mode-`0600` configuration file.
